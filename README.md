# Бухгалтерия — бот + личный кабинет (Telegram Mini App)

Телеграм-бот для учёта финансов с личным кабинетом на сайте, который
открывается прямо внутри Telegram (Mini App). Бот и сайт работают
с одной и той же базой данных — доход или расход, добавленный
в одном месте, сразу виден в другом.

## Возможности

- Доходы / расходы по категориям (бот и сайт)
- Обмен наличных на карту с учётом комиссии — комиссия автоматически
  списывается как расход "Комиссия за обмен"
- Долги (кто должен вам / вы должны)
- Статистика: сегодня / неделя / месяц, топ-категория
- Личный кабинет (Mini App) — та же функциональность на сайте,
  вход автоматический через Telegram, без пароля
- Напоминания: если за 7 дней расходы превысили порог, или если
  за день не было ни одной записи — бот сам напишет

## Railway: переменные окружения

| Переменная            | Описание                                                          |
|------------------------|--------------------------------------------------------------------|
| BOT_TOKEN               | Токен от @BotFather                                                 |
| DATABASE_URL             | Автоматически от Railway PostgreSQL                                  |
| WEB_SECRET                | Секрет для Flask-сессий (любая случайная строка)                      |
| WEBAPP_URL                 | Публичный https-адрес сайта, например `https://bugalterbot.up.railway.app` |
| WEEKLY_ALERT_THRESHOLD       | Порог расходов за неделю для уведомления (по умолчанию 200000)             |
| REMINDER_HOUR                 | Час по Ташкенту для ежедневной проверки (по умолчанию 20)                    |
| PORT                             | Railway задаёт автоматически                                                    |

## Деплой

1. Создай проект на Railway
2. Добавь **PostgreSQL** сервис (DATABASE_URL подставится автоматически)
3. Загрузи код через GitHub или Railway CLI
4. В настройках сервиса включи **Public Domain**, скопируй адрес
   и укажи его в переменной `WEBAPP_URL` (обязательно с `https://`)
5. Установи остальные переменные из таблицы выше
6. Deploy!

## Как это работает

- В Telegram у бота в меню появляется кнопка **«🧮 Кабинет»** —
  это WebApp-кнопка, она откроет `WEBAPP_URL/app` прямо внутри Telegram.
- Сайт получает `initData` от Telegram, проверяет подпись по `BOT_TOKEN`
  (без этого зайти в чужой кабинет невозможно) и открывает кабинет
  именно того пользователя, который его открыл — паролей и логинов нет.
- Если открыть сайт не через кнопку бота (просто по ссылке в браузере),
  `initData` будет пустым, и сайт покажет подсказку открыть через бота.
